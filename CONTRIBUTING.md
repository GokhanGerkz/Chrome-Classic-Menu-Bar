# Contributing

Thank you for considering a contribution.

## Before opening an issue

- Confirm the problem occurs with the latest Google Chrome and Windhawk versions.
- Restart Chrome after enabling the mod.
- Check whether another Windhawk mod changes Chrome's title bar or non-client frame.

## Pull requests

1. Fork the repository.
2. Create a focused branch.
3. Keep the Windhawk metadata block valid.
4. Preserve the mod ID and source filename.
5. Test with normal, maximized, restored, and multi-window Chrome states.
6. Describe the behavioural change and testing performed.

Avoid unrelated formatting changes in functional pull requests.
