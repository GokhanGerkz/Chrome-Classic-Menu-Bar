# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-08-05

### Added

- First GitHub-ready stable release.
- Native File, Edit, View, History, Bookmarks, Tools, and Help menu bar.
- Owner-drawn dark menu mode.
- Automatic Chrome window detection and reattachment.
- DPI-aware menu measurement and drawing.
- Shortcuts and launchers for common Chrome commands and internal pages.
- GitHub documentation, issue templates, validation workflow, and Windhawk submission copy.

## [0.6.0]

- Original working development version.
