# Installation

## Manual installation in Windhawk

1. Install and open Windhawk.
2. Choose **Create a new mod**.
3. Open `src/chrome-classic-menu-bar.wh.cpp` from this repository.
4. Copy the entire file into the Windhawk editor.
5. Compile and enable the mod.
6. Restart all Chrome windows if required.

## Troubleshooting

- Confirm the target process is `chrome.exe`.
- Disable other title-bar or Chrome frame mods temporarily to check for conflicts.
- Close every Chrome background process and reopen Chrome.
- Review the Windhawk mod log for attachment or hook failures.
