For an official submission:

1. Fork the official Windhawk mods repository on GitHub.
2. Create a branch in your fork.
3. Copy the prepared file into the fork's `mods` directory.
4. Commit the file.
5. Open a pull request from your branch to the official repository.
6. Respond to any automated validation or maintainer feedback.

Only submit source that you have tested and are comfortable publishing under the selected license.
